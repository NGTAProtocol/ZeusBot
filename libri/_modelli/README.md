# Modelli

Struttura di ogni libro in `libri/<nome>/`:

- `00-progetto/` — stato.md (fase, decisioni, cose DA DEFINIRE), piano.md
- `01-mercato/` — posizionamento, comparabili, lettore ideale (Fase 1)
- `02-bibbia/` — bibbia.md, idea-di-controllo, trama, voce-e-stile, luoghi, mondo, personaggi/
- `03-architettura/` — scaletta per parti e capitoli, piano parole (Fase 2)
- `04-manoscritto/` — capitoli
- `05-revisioni/` — prove di voce, note di revisione

Il libro su cui si lavora è indicato in `libri/libro-attivo.md`.
