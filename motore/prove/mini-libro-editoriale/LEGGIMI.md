# Mini-libro editoriale (prove)

Libro inventato, con autrice inventata, per le prove del percorso da casa editrice (`script/prove_editoriale.py`).
Nessun riferimento a libri, autori o luoghi reali. Non è un libro del motore: è un insieme di file che la
prova copia in un repository temporaneo, un passo alla volta:

- `briefing.md`: il briefing che `zb nuovo` trasforma nel libro (percorso editoriale);
- `struttura/`: i nove file di `03-struttura/` scritti dall'«architetto»;
- `codex/`: schede in più per il codex (luoghi);
- `capitoli/`: i tre capitoli scritti dallo «scrittore»;
- `capsule/`: le capsule compilate dall'agente «capsula»;
- `rapporti/`: i rapporti dei ruoli di revisione (la prima riga la completa la prova con `zb ruolo`);
- `traduzione-en/`: guida, glossario e capitoli tradotti in inglese.
