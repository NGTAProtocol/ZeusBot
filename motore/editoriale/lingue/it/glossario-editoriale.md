# Glossario editoriale (italiano)

Termini del mestiere usati da ruoli, rapporti e comandi. Un termine, un significato.

| Termine | Significato nel motore |
|---|---|
| briefing | ciò che l'autore vuole: il cosa del libro |
| struttura | i nove file di `03-struttura/`, decisi prima della prosa |
| macrostruttura | la forma d'insieme scelta e motivata (3 atti, dittico, mosaico…) |
| scheda del capitolo | il blocco del capitolo in `05-scaletta.md` |
| codex | schede di personaggi e luoghi con i tag `@char` e `@loc` |
| canone | fatti bloccati in `stato.yaml`; cambiano solo con il gate `canone` |
| capsula | sintesi di continuità di un capitolo, 120-250 parole (circa 180) |
| stato compatto | 15-20 righe da leggere all'inizio di una sessione |
| diagnosi | lettura che descrive e misura, senza riscrivere |
| piano di revisione | interventi decisi dall'editor strutturale, approvati al gate |
| line editing | lavoro sulla frase: ritmo, voce, chiarezza |
| copyediting | correzione di lingua e coerenza |
| bozze | controllo del libro impaginato |
| gate | fermata con l'approvazione dell'autore (`avanti`, `ok`, `correggi`) |
| proposta | intervento scritto in un rapporto; si applica solo dopo l'«ok» |
