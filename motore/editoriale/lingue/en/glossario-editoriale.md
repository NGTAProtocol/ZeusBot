# Editorial glossary (English)

Trade terms used by roles, reports and commands for books written or translated into English. The engine's
file and command names stay in Italian; this table gives the English meaning.

| Engine term | English | Meaning |
|---|---|---|
| briefing | brief | what the author wants the book to be |
| struttura | structure | the nine files in `03-struttura/`, decided before any prose |
| macrostruttura | macrostructure | the overall shape, chosen and justified |
| scheda del capitolo | chapter card | the chapter's block in `05-scaletta.md` |
| codex | codex | character and place cards tagged `@char` / `@loc` |
| canone | canon | locked facts; changed only through the `canone` gate |
| capsula | continuity capsule | about 180 words per chapter |
| stato compatto | compact state | 15-20 lines read at the start of a session |
| diagnosi | diagnostic read | describes and measures; does not rewrite |
| piano di revisione | revision plan | structural editor's interventions, approved at the gate |
| line editing | line editing | sentence-level work: rhythm, voice, clarity |
| copyediting | copyediting | language and consistency corrections |
| bozze | proofs | check of the typeset book |
| gate | gate | author approval stop (`avanti` = next, `ok`, `correggi` = correct) |
